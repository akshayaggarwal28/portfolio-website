Drop the top-right hero slideshow photos here, named so they sort in the
order you want them shown:

  hero-1.jpg   (shown first)
  hero-2.jpg
  hero-3.jpg
  hero-4.jpg
  ...

Any .jpg / .jpeg / .png / .webp works. Filenames are sorted alphabetically,
so zero-pad if you go past 9 (hero-01, hero-02, ...). The slideshow picks
them up automatically — no code changes needed.
